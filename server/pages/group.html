Group Preset

A Group Preset is a way to export and import all of a group's settings.

From this group's current settings, click Generate Code for a copy-and-paste string, or Generate Link for a shareable link. Opening the link creates a new group with those settings, or applies them to your current group if you're its leader.

To load a Group Preset if you're the group leader, paste the code (or a link) in the field above and click Load (this will override all of the group's current settings).
