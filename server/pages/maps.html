Create Custom Maps

TagPro maps are made by our community. To make your own custom maps for TagPro you can use the community created map editor. There are tons of player-made maps available there.

Check our wiki too

Map Testing

Maps can be tested by creating a private group and enabling the Map Testing Mode option. If you launch a map directly from Fortunate Maps or the map editor, a Map Testing Mode group will automatically be created.

A Map Testing Mode group is similar to a regular private group but with the following special behaviors:

  • The game defaults to 10 minutes long with no mercy rule and no analytics collected.
  • The AFK timer is relaxed.
  • Players can switch teams at any time.
  • Any player can press "r" at any time during the game to reset all map elements to their active state.
  • The game screen shows a special URL including a game id. You can share this link with a friend and they'll be joined directly into both the group and the game.

Rotation Maps

To have your map added to the official public map rotation the Map Testing Committee must judge your map and accept it. Players who have maps added to rotation are awarded with the and flair.

Trial Maps

New maps can be submitted through the CreativeTPBot on the official TagPro Discord. If the Map Testing Committee approves the submission, the map will enter Trial rotation and will spawn with half the frequency of Rotation maps. Community votes will help decide if the map will enter regular rotation.

Classic Rotation Maps

Maps that have been taken out of rotation, can periodically be added to the "Classic rotation". Maps in this category spawns half as much as rotation maps, and this category changes with every rotation.

Retired Maps

When a map is taken out of public rotation it joins the retired maps. Maps in this category are playable from private games.
